# JamieLab - Personal Cybersecurity Lab Website

A Jekyll-based personal website showcasing homelab experiments, security projects, and technical notes.

## Features

- 📝 Blog with search functionality and RSS feed
- 🚀 Project showcases with status tracking
- 🏠 Homelab infrastructure documentation
- 📓 Interactive notes system with local storage
- 🔍 Client-side search across content
- 📋 One-click code copying
- 📱 Mobile-responsive design
- 🎨 **5 customizable themes** including Soft Matrix (easy on the eyes)
- 🌓 **Dark/Light mode toggle** with preference persistence
- 🔗 SEO optimized with sitemap and Open Graph tags
- ♿ Accessibility features and print-friendly layouts

## Quick Start

```bash
# Install dependencies
bundle install

# Run locally
bundle exec jekyll serve

# Build for production
bundle exec jekyll build
```
