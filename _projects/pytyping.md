# PyTyping

**Status:** Active  
**Tags:** python, pyqt, typing, ui

## Overview

PyTyping is a lightweight typing trainer focused on quick sessions, clear feedback, and real improvement. It runs locally and aims to stay simple, fast, and distraction-free.
